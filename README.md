# 寂靜光年 | SILENT LIGHTYEAR

一個以電影感深空美學打造的宇宙天體觀測檔案館，收錄太陽系行星、衛星、恆星黑洞、黃道十二星座、夜空星座與深空星系等 36 筆天體資料。

## 特色功能
- **模組化 PHP 架構**：資料與版面分離（`data.php`、`header.php`、`footer.php`），支援動態分類篩選與關鍵字即時搜尋。
- **電影級動態視覺**：首頁 Ken Burns 呼吸式深空背景縮放、3D CSS 渲染氣態木星、立體自轉行星卡片，以及頂天立地巨幅靜止詳情頁。
- **全裝置響應式設計**：基於 Bootstrap 5.3 與自訂 CSS 打造的深空暗黑介面。

## 本地執行方式
1. 安裝並啟動 XAMPP（開啟 Apache 模組）。
2. 將本專案資料夾放入 `htdocs/silent-lightyear`。
3. 瀏覽器開啟 `http://localhost/silent-lightyear/`。
